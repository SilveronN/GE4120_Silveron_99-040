# Instruction:
### We were tasked to create our personal Branding using our own designs, following a format for our fonts and colors.

# Reflection:
### I learned that personal branding is about being consistent, so using the same fonts and colors across my designs makes my work look unified and easy to recognize. Following a set format showed me that limits can actually help, since I had to make creative choices within a clear style guide. This activity also helped me think about how I want to present myself to others, especially as I prepare for opportunities like OJT.
