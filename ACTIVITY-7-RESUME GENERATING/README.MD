# Instruction

### In this laboratory activity, students will explore how different Large Language Models (LLMs) generate content by using the same prompt across multiple platforms. Students will create a one-page professional resume by prompting at least two LLM tools, then analyze and compare the outputs.

# Reflection:
### I learned that the quality of an AI-made resume depends on how detailed my prompt is. The first output was generic, while the refined one was more accurate and professional because I added details like my course, skills, and the kind of job I wanted. Comparing the two helped me explain why the second was better: a clearer prompt gives clearer, more relevant results. I also learned that I still need to check AI outputs for mistakes or missing information before using them.
